## 用 skill 的方式

Chief of SEO agent 自动调；用户也可以直接说：

> "用 `title-meta-rewriter` 给 query 'best crm' 改 3 个 title 候选"

skill 文件的**结构**：
- 角色（你能做什么）
- 输入（要什么参数）
- 工具（用哪些 MCP tool）
- 工作流（步骤清单）
- 输出格式（结构化 markdown）
- 边界（什么时候停止）
- 失败模式（避免什么）
