# 26 步法 · 阶段 3：页面模板

> 对应 Nicholas Dulait 原文步骤 8-15

## 阶段目标

基于你前面挖出的「关键词 → 页面树」，**为每种页面类型设计可复用的模板**。
模板定下来后，写新页面就是"填空"——而不是从零开始。

## 步骤 8：定义页面类型清单

你有几类页面？通常是：

| 类型 | 例子 | 优化目标 |
|---|---|---|
| **首页** | `/` | 品牌词 + 父级大词 |
| **品类页 (Category)** | `/best-crm` | 商业意图主词（"best X"）|
| **产品页 (Product)** | `/products/xyz` | 交易意图（"buy X"） |
| **对比页 (Comparison)** | `/hubspot-vs-mailchimp` | 商业意图对比（"X vs Y"）|
| **测评页 (Review)** | `/hubspot-review` | 商业意图（"X review"）|
| **How-to 教程** | `/how-to-use-crm` | 信息意图（少做）|
| **Listicle 列表** | `/7-best-crm-tools` | 商业意图 |
| **Glossary 定义** | `/what-is-crm` | 信息意图（少做）|

**给 Claude**：

```
我需要为我的站 [your-site] 设计 5-8 个页面模板。

我的产品/服务：[描述]
我的主要关键词群：[关键词树]
我现有的页面：[list]

请你：
1. 我应该有哪些页面类型？给出每种类型的：
   - 目标关键词（什么词打这个页面）
   - 页面目的（用户来这想干啥）
   - 唯一性（这一类不跟其他类重复）
2. 每种类型给 1-2 个参考 URL（公开的同行）
```

## 步骤 9-15：写每个模板（关键步骤）

对每种页面类型，**用同一个结构**写模板：

### 模板结构

```markdown
# [页面类型] 模板

## 1. 标题公式
[Title pattern]
举例：[实际例子 1]
举例：[实际例子 2]

## 2. Meta description 公式
[150 字符以内]
举例：[例子 1]

## 3. H1
[唯一性：跟 title 略不同但语义同]

## 4. 页面结构（章节顺序）
### 引言（80-150 字）
- 钩子：用户来这里要解决什么
- 信用：你是谁 / 为什么信你
- 承诺：看完能得到什么

### 主体（按类型变化）
- 品类页：列出 5-10 个候选 → 每个给评分
- 对比页：X 适合谁 / Y 适合谁 / 表格式对比
- 测评页：评分 + 优点 + 缺点 + 谁该用 + 谁不该用
- How-to：步骤 1-7，每步截图

### 结论
- TL;DR（一段话总结）
- CTA（你下一步该做啥）
- FAQ（3-5 个问题，针对 People Also Ask）

## 5. 关键词密度
- 主词：[X] 次（出现 N 次，不刻意）
- 长尾变体：自然使用

## 6. 长度
- 词数：[范围]
- 段落：每段 ≤ 80 字
- 图片：[N] 张

## 7. Schema markup
- 品类页：ItemList
- 产品页：Product
- 测评页：Review / Product（双重）
- How-to：HowTo

## 8. 内链
- 必链到：[Pillar 页面 / 父分类]
- 可链到：[相关文章 1-3 篇]

## 9. CTA
- 主 CTA：[免费试用 / 联系 / 下载]
- 次 CTA：[订阅 newsletter / 关注 social]
```

**给 Claude**：

```
现在我请你按上面的结构，**为我写 [品类页] 的完整模板**。
我的 niche 是 [CRM / k8s / 健身...]。

模板里：
- 标题公式给 5 个变体（我能换着用）
- 段落给 1 个完整段落的范例（80-150 字，能直接 copy 改）
- 内链规则要具体（链到哪个 URL 模式，比如 /blog/[slug]）
- CTA 要符合 [B2B SaaS / B2C 电商 / 媒体] 的常见模式
```

## 步骤 13-15：批量生产

模板定好之后：
- 一次写 **2-3 个页面**（先验证模板好不好用）
- 改 1-2 轮模板（基于实际写得顺不顺）
- 然后**批量化**（每周 3-5 个新页）

## 这一阶段你的产物

✅ 5-8 个页面类型清单
✅ 1-2 个**完整可用**的模板（不是占位符）
✅ 至少 1 个用模板写出来的页面（验证模板）

## 用本项目工具

- `keyword_research_tool(seed)` — 验证模板目标词的 volume / difficulty
- `audit_page_tool(url)` — 写完后过一遍 audit
- `gsc_top_pages_tool` — 看现有页面分布（避免跟已存在的重复）
