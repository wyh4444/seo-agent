# 26 步法 · 阶段 5：节奏与规模化

> 对应 Nicholas Dulait 原文步骤 20-26

## 阶段目标

**单个页面流程跑通后，怎么持续生产 + 怎么避免"做完了没数据"的迷茫**。

## 步骤 20：内容节奏（Content Pacing）

| 站规模 | 节奏 | 每月产出 |
|---|---|---|
| 小（1-3 人） | 1 篇/周 | 4-6 篇/月 |
| 中（5-10 人） | 2-3 篇/周 | 8-12 篇/月 |
| 大（10+ 人） | 5-10 篇/周 | 20-40 篇/月 |

**核心规则**：
- **固定节奏**比"灵感来了就写"重要
- 每周固定 1 天 1 小时做 keyword research（不是写作时临时找）
- 写作日 vs 编辑日分开（避免 context switching）

**给 Claude**：

```
我是 [独立开发者 / 小团队 / 中型] 站。
我的目标：[X] 篇/月。
请给我一个**6 个月**的内容排期模板：

- 每月 X 篇，分布到周几
- 每周写作日 vs 调研日的分工
- 季度复核的节奏（每 3 月做一次全站 review）
```

## 步骤 21-22：更新旧内容（避免内容腐烂）

**现实**：2 年前写的"2024 最佳 CRM"现在是垃圾。Google 看 freshness。

**给 Claude**：

```
这是我的 5-10 个**最核心页面** URL：
[URLs]

请告诉我：
- 每个页面的"内容腐烂风险"（高/中/低）
- 何时该更新（发布后 N 月）
- 更新时改什么（数据 / 截图 / 案例）
```

**判断腐烂的 3 个信号**：
- GSC 里 position 持续下滑
- CTR 持续下滑（即使 position 没变）
- 内容里有具体年份 / 数据，过期了

## 步骤 23-24：内链 + 外链

### 内链（你能控制）
- 每月固定 1 次"内链巡检"：看你有什么新文章，加到相关文章里
- 调本项目 `gsc_top_pages_tool` 看现有页面 → 给新内容加链接

### 外链（你只能求）
- **不要**买链接
- **能做的**：给同行 / 媒体发 pitch（"我这有数据，引用吗？"）
- 1 个月能有 1-2 条 DR 30+ 的外链已经很好

**给 Claude**：

```
我有一份数据 / 调研 / 行业报告 [描述]
请给我 5-10 个**可能想引用这个数据**的媒体 / 博客 / 报告作者。

要求：
- 找真实的 email 或联系页
- 给每个写一封 100 字的 pitch 模板
- 不要发垃圾邮件的语气
```

## 步骤 25-26：度量 + 调优

### 每周看的 3 个数

| 指标 | 工具 | 看什么 |
|---|---|---|
| 总 clicks | GSC | 周环比 + 同比 |
| 总 impressions | GSC | 增长还是平 |
| 平均 position | GSC | 是涨是跌 |

### 每月看的 5 个数

- Top 10 queries（CTR 升了还是跌了）
- Top 10 pages
- New vs Returning
- Indexed pages（用 `site:your-site.com` 查）
- Backlinks 新增（用 DataForSEO backlinks / Ahrefs / Semrush）

### 季度看的 1 件事

- **目标词 SERP 变化**（你打的 30 个词，position 分布怎么变）

**给 Claude**：

```
请基于 [我的 GSC 数据 / 截图] 给我一份**月度报告**：
- 上月总结（3 句话）
- Top 3 增长 / Top 3 下滑
- 下月建议（3 个具体动作）
```

## 节奏模板（6 个月）

```
Month 1: 模板 + 1-2 个 seed 页面
Month 2: 5-8 个页面 + 第一次季度复核
Month 3: 8-10 个页面 + 第一次外链 outreach
Month 4: 10-12 个页面 + 更新 Month 1 的 2 个老页
Month 5: 12-15 个页面 + 第二次季度复核
Month 6: 15-20 个页面 + 看哪个 pillar 流量起来了
```
